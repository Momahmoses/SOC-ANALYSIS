# Security Operations Center (SOC) Analysis

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Comprehensive SOC analysis project covering threat detection, log analysis, incident response, and cybersecurity monitoring, applying data analysis techniques to security event data.

---

## Overview

This project demonstrates SOC analyst workflows using Python, from ingesting and parsing security logs to detecting anomalies, classifying threats, and generating incident reports. It bridges data science and cybersecurity operations.

---

## Topics Covered

| Topic | Description |
|-------|-------------|
| Log Parsing & Normalisation | SIEM log ingestion and field extraction |
| Anomaly Detection | Baseline profiling and statistical outlier detection |
| Threat Classification | ML-based categorisation of security events |
| Incident Timeline | Chronological attack chain reconstruction |
| IOC Analysis | IP, hash, and domain indicator analysis |
| Reporting | Automated incident report generation |

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Analysis | pandas, NumPy |
| Machine Learning | scikit-learn |
| Visualisation | Matplotlib, Seaborn |
| Security | python-ioc, hashlib |
| Notebooks | Jupyter Notebook |
